
# ⭐ Star Rating Widget

An interactive five-star rating component built using HTML, CSS, and JavaScript.

## Features

- Five clickable stars for rating from 1 to 5.
- Hover preview effect.
- Displays the selected rating and feedback message.
- Stores the selected rating in JavaScript state.
- Reset button to clear the rating.
- Responsive design for mobile and desktop.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Widget structure
- `style.css` — Styling and hover effects
- `script.js` — Rating selection and reset functionality

## How to Use

1. Hover over the stars to preview a rating.
2. Click a star to select your rating.
3. View the selected rating and feedback.
4. Click Reset Rating to start again.
